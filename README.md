# BharatFinRAG
An AI-powered Retrieval-Augmented Generation (RAG) system for analyzing Indian companies' annual reports, financial statements, and corporate filings. Uses Large Language Models (LLMs), vector search, and source-grounded answers to help users understand company financials, business performance, and key financial metrics.



# What is RAG?
RAG - Retrieval-Augmented Generation (RAG) is a framework that combines retrieval-based methods with generative models to enhance the quality and relevance of generated responses. It leverages external knowledge sources to provide contextually accurate and informative outputs, making it suitable for various applications such as chatbots, enterprise search, and knowledge-heavy systems.
